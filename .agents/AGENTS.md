# Regras Gerais do Workspace

- **Commit Messages (CRITICAL):** When you are invoked to generate a git commit message, you MUST analyze the diff and write BOTH the title and the description EXCLUSIVELY in Brazilian Portuguese (pt-BR). Do not use English under any circumstances. Example: "feat: adicionar novo gráfico".
- **Consistência de Código:** Toda codificação a ser criada ou alterada deve manter estritamente o estilo da codificação atual do projeto. Isso inclui estilo de nomenclaturas, formato e tamanho de funções, ordem estrutural do código, padrão de comentários e uso das tecnologias já presentes. O código gerado deve parecer organicamente escrito seguindo a mesma linha de construção atual.
